# 01 · 快速开始

[English](en/01-quickstart.md) | 中文

目标：5 分钟在本机跑起来，拿到一个能用的 OpenAI 兼容接口 + 控制面板。

## 0. 前置

- Python 3.10+（3.11/3.12 均可）
- 已在电脑上安装并登录 **WorkBuddy 桌面端**（token 来自这里）

## 1. 拉代码

```bash
git clone https://github.com/<you>/workbuddy2api.git
cd workbuddy2api
```

## 2. 配置文件

```bash
cp .env.example .env
```

编辑 `.env`，至少改这三行：

```ini
CODEBUDDY_AUTH_TOKEN=<你的 access token>
API_KEY=<自己编一个，例如 sk-wb-xxxxxxxx>
ADMIN_PASSWORD=<控制面板密码>
```

生成一个随机 API_KEY：

```bash
python -c "import secrets;print('sk-wb-'+secrets.token_hex(20))"
```

## 3. 拿 token

```bash
python tools/get_token.py
```

- 如果本地是**明文**存储 → 直接读到，加 `--write` 就写进 `.env` 了：

  ```bash
  python tools/get_token.py --write
  ```

- 如果提示「token 已被加密存储」→ 用抓包法，30 秒：

  1. 打开 WorkBuddy 桌面端（已登录）
  2. `F12` → **Network** 面板
  3. 在客户端里随便发一条消息
  4. 找到发往 `copilot.tencent.com` 的请求 → 复制请求头
     `Authorization: Bearer eyJhbGciOi...`，`Bearer ` 后面那一整串就是 access token
  5. 写进 `.env`：

     ```bash
     python tools/get_token.py --access <刚才复制的> --write
     ```

  详见 [02-获取Token.md](02-获取Token.md)。

## 4. 装依赖、启动

```bash
pip install fastapi uvicorn

# 方式 A：直接跑（会自动读取同目录的 .env）
python server.py

# 方式 B：用脚本（额外做了解释器探测，会挑一个装了 fastapi 的 Python）
bash start.sh
```

> `server.py` 启动时会自动加载同目录的 `.env`，**已存在的环境变量优先**、不会被文件覆盖。
> 所以你可以直接用 `.env`，也可以用 `export CODEBUDDY_AUTH_TOKEN=...` 临时覆盖。

看到这样的输出就成功了：

```
[*] 已从 .env 加载 15 项配置
[✓] CodeBuddy client 初始化成功
[✓] 控制面板就绪  db=<项目目录>/admin.db  /admin
INFO:     Uvicorn running on http://0.0.0.0:8000
```

## 5. 验证

```bash
KEY=$(grep '^API_KEY=' .env | cut -d= -f2-)

curl http://127.0.0.1:8000/health
curl http://127.0.0.1:8000/v1/models -H "Authorization: Bearer $KEY"
curl http://127.0.0.1:8000/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H 'Content-Type: application/json' \
  -d '{"model":"deepseek-v3","messages":[{"role":"user","content":"你好"}],"stream":false}'
```

浏览器打开 <http://127.0.0.1:8000/admin>，用 `ADMIN_PASSWORD` 登录，能看到积分和密钥管理。

## 6. 接到客户端

Base URL：`http://127.0.0.1:8000/v1`，API Key 填 `.env` 里的 `API_KEY`。

各客户端的具体填法看 [使用指南.md](使用指南.md)。

## 本机常见坑

- **端口被占**：`.env` 里改 `PORT=`。
- **Windows 其他设备连不上**：防火墙没放行。管理员运行 `enable_lan.ps1`。
- **`pip install` 后仍报缺 fastapi**：多半是机器上有多个 Python（比如 conda / 系统 Python / 某个自带的 Python）。
  用 `python -c "import sys;print(sys.executable)"` 确认你装包和跑服务的是同一个解释器。
- **开了系统代理的话**，本地 curl 测试加 `--noproxy '*'`，否则可能被代理拦截成 502。
