# 07 · 常见问题与报错对照

## 启动 / 配置

**`请安装依赖: pip install fastapi uvicorn`**

机器上有多个 Python，装包和跑服务用的不是同一个解释器：

```bash
python -c "import sys;print(sys.executable)"    # 看当前是哪个
```

用这个解释器装依赖再跑，或者直接改用 `python -m uvicorn server:app --host 0.0.0.0 --port 8000`。

---

**`[!] 未设置 CODEBUDDY_AUTH_TOKEN`**

`.env` 没被读到，或者没填 token。确认：

- 当前目录下确实有 `.env`（`ls -la .env`）
- `CODEBUDDY_AUTH_TOKEN=` 后面有值，没被引号包住、没有多余空格
- 用 `bash start.sh` 启动（它会自动加载 `.env`）；直接 `python server.py` 则需要你自己保证环境变量已注入

---

**`初始化失败: 无法获取 token`**

`.env` 里没 token，且本地 auth 文件也读不到 → 按 [02-获取Token.md](02-获取Token.md) 抓包。

---

**端口被占**

```
[Errno 98] Address already in use
```

`.env` 改 `PORT=8001`，或杀掉占用进程。

## 请求报错

| 返回 | 原因 | 处理 |
|---|---|---|
| `401 Missing or invalid Authorization header` | 没带 `Authorization` 头，或少了 `Bearer ` 前缀 | 补上 `Authorization: Bearer <key>` |
| `403 Invalid API key` | Key 不对 | 从 `.env` 或控制面板复制 |
| `403 该 API Key 已被禁用` | 密钥被停用 | 面板里启用 |
| `403 该 API Key 已过期` | 超过有效期 | 面板里改有效期或重新签发 |
| `403 额度已用完（x/y 积分）` | 额度耗尽 | 面板里重置用量或提高额度 |
| `503 CodeBuddy token not configured` | 服务端上游 token 丢了 | 检查 `.env`，重启 |
| `502 Upstream API error` | 上游连接异常 | 先重试；持续失败看 `logs` |
| `502 Upstream API returned empty response` | 模型 id 不可用，或上游抽风 | 换模型重试；确认 id 拼写 |
| `400 messages is required` | 请求体缺 `messages` | 标准 OpenAI 格式 |
| `400 Invalid JSON body` | JSON 语法错 | 检查转义/引号 |

## 流式相关问题

**客户端一直转圈，最后一次性吐出来**

上游本来就只支持流式，本服务是"先收完整段、再按块推给客户端"。所以：

- 客户端能正常显示打字机效果
- 但**首字延迟 = 整段生成时间**，不是逐 token 的真实时延

这是上游接口形态决定的，不是 bug。

**反向代理后面流式卡住**

必须关掉代理缓冲：

```nginx
proxy_buffering off;
proxy_cache off;
proxy_read_timeout 300s;
```

Caddy 用 `flush_interval -1`。

## 并发

**只有一个客户端时一切正常，多设备同时用就随机 502 / 报错**

老版本这里是单条 HTTP 长连接 + 多线程并发，会串包（`CannotSendRequest`、
`'NoneType' object has no attribute 'read'`）。当前实现已把连接按线程隔离，支持并发。

如果你的 fork 还是老代码，检查 `codebuddy_direct_api.py` 里 `_conn` 是不是 `threading.local()` 实现。

另外上游本身有请求间隔限速（`RateLimiter`），高并发会被自动排队，这是反封号保护，不是故障。

## Docker / CasaOS

**容器一直 `restarting`**

看日志找原因：

```bash
python update.py logs
# 或
docker logs workbuddy2api
```

最常见的两个：

1. 启动命令里用了 `curl` / `wget` —— `python:*-slim` 镜像**没有**这两个命令
2. 环境变量没注入，`ADMIN_DB` 指向了不存在的目录

---

**CasaOS 安装自定义应用失败**

| 报错 | 原因 |
|---|---|
| `main service not been specified` | 贴进去的不是合法 YAML（常见于用 JSON 传） |
| `there are ports in use` | 端口被占 |
| `is already being installed` | 上次异步安装还没结束，等一会儿 |
| 装完不出现 | 自定义应用必须 `uncontrolled=true` |

---

**升级后密钥 / 日志没了**

`admin.db` 没挂载到卷里。把 `/data` 挂到宿主目录（比如 `/DATA/AppData/workbuddy2api`），
并设 `ADMIN_DB=/data/admin.db`。

---

**token 一天后失效，要重新抓**

`CODEBUDDY_REFRESH_TOKEN` 没填，或者容器没挂数据卷导致刷新后的 token 丢了。
补上 `CODEBUDDY_REFRESH_TOKEN` 并挂载 `/data`（`CODEBUDDY_TOKEN_CACHE=/data/token.json`）。

## 网络 / IPv6

**其他设备连不上**

- 本机防火墙没放行（Windows：管理员跑 `enable_lan.ps1`）
- 云服务器安全组没放行端口
- 域名只解析到 IPv6（只有 AAAA 记录）→ **没有 IPv6 的设备根本连不上**。
  用 `nslookup -type=A 你的域名` 确认有没有 A 记录

---

**本地 curl 测试返回 502，但服务明明正常**

本机设了 `http_proxy`，curl 走了代理。判断：

```bash
curl -s -o /dev/null -w '%{remote_ip}\n' http://你的地址:8000/health
```

如果显示 `127.0.0.1`，说明走的是本地代理。测试时加 `--noproxy '*'`。

## 控制面板

**打不开 /admin，返回 404**

代码里没有 `static/admin.html`。检查打包（容器里 `ls /app/static`）或重新 `python update.py`。

**登录提示"服务端未设置 ADMIN_PASSWORD"**

`.env` 里没填 `ADMIN_PASSWORD`，或者容器没读到。填上后重启。

**"尝试过于频繁，请 5 分钟后再试"**

登录失败 5 分钟内超过 10 次，等一会儿。

**积分显示"—"**

上游计费接口查询失败，面板顶部会显示具体错误。常见原因：
token 失效、`CODEBUDDY_BILLING_BASE` 配错（**不要带 `/v2` 前缀**）、服务器出网受限。
