# 客户端接入指南

[English](en/clients.md) | 中文

本文假设你已经跑起了服务，地址是 `http://your-host:8000`（本机就是 `http://127.0.0.1:8000`）。

## 三个必填项

| 项 | 值 |
|---|---|
| **Base URL** | `http://your-host:8000/v1` |
| **API Key** | `.env` 里的 `API_KEY`，或在控制面板新签发的分发密钥 |
| **模型名** | `deepseek-v3` 等，完整清单见 [06-模型与探测.md](06-模型与探测.md) |

鉴权方式就是标准头：`Authorization: Bearer <API_KEY>`。

> **`/v1` 到底写不写？** 看客户端：自带 `/v1` 的填 `http://your-host:8000`，不带的填 `http://your-host:8000/v1`。
> 判断方法：填完点「获取模型列表」，能拉出 35 个模型就对了。

## GUI 客户端

**Cherry Studio / ChatBox / LobeChat / NextChat / Open WebUI / OneAPI**

1. 添加供应商 → 选「OpenAI」或「自定义 OpenAI」
2. API 地址：`http://your-host:8000/v1`
3. API Key：你的 key
4. 模型：点「获取模型列表」自动拉取，或手填 `deepseek-v3`

这些客户端在浏览器/Electron 里发请求，服务端已开 `CORS: *`，可直接用。

**沉浸式翻译 / 划词翻译类插件**

- 自定义 API 域名：`http://your-host:8000`
- 模型建议选响应快的：`glm-5.0-turbo`、`kimi-k2.7`

**Cursor / Continue / Cline（VS Code 插件）**

- Provider 选 `OpenAI Compatible`
- Base URL：`http://your-host:8000/v1`
- 模型名手填（不支持自动拉取的插件）：`deepseek-v3`
- Cursor 的 Verify 按钮就是调 `/v1/models`，能过说明配对了

**Dify / FastGPT / n8n**

- 新建「OpenAI-API-compatible」模型供应商
- API endpoint：`http://your-host:8000/v1`
- 模型名称需按清单逐个添加

**SillyTavern**

- API 选 `OpenAI Compatible`
- 反向代理地址：`http://your-host:8000/v1`
- 自定义模型名填 `deepseek-v3`

## 代码调用

**Python（openai >= 1.0）**

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://your-host:8000/v1",
    api_key="<API_KEY>",
)

resp = client.chat.completions.create(
    model="deepseek-v3",
    messages=[{"role": "user", "content": "你好"}],
    extra_body={"reasoning_effort": "low"},   # 可选：low/medium/high/max
)
print(resp.choices[0].message.content)
```

流式：

```python
stream = client.chat.completions.create(
    model="deepseek-v3",
    messages=[{"role": "user", "content": "写一首关于秋天的诗"}],
    stream=True,
)
for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="", flush=True)
```

**Node.js**

```js
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "http://your-host:8000/v1",
  apiKey: "<API_KEY>",
});

const r = await client.chat.completions.create({
  model: "deepseek-v3",
  messages: [{ role: "user", content: "你好" }],
});
console.log(r.choices[0].message.content);
```

**LangChain**

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="deepseek-v3",
    base_url="http://your-host:8000/v1",
    api_key="<API_KEY>",
)
print(llm.invoke("你好").content)
```

## curl 速查

```bash
KEY=<API_KEY>
B=http://your-host:8000

# 健康检查（不需要 key）
curl $B/health

# 模型列表
curl $B/v1/models -H "Authorization: Bearer $KEY"

# 对话（非流式）
curl $B/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H 'Content-Type: application/json' \
  -d '{"model":"deepseek-v3","messages":[{"role":"user","content":"你好"}],"stream":false}'

# 对话（流式）
curl -N $B/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H 'Content-Type: application/json' \
  -d '{"model":"deepseek-v3","messages":[{"role":"user","content":"你好"}],"stream":true}'

# 文生图
curl $B/v1/images/generations \
  -H "Authorization: Bearer $KEY" -H 'Content-Type: application/json' \
  -d '{"model":"hunyuan-image-v3.0","prompt":"一只橘猫坐在窗台上","size":"1024x1024"}'

# 图生图（image 支持 http URL / data URL / 纯 base64）
curl $B/v1/images/edits \
  -H "Authorization: Bearer $KEY" -H 'Content-Type: application/json' \
  -d '{"prompt":"把背景换成雪景","image":"https://example.com/a.png"}'
```

> 本机如果开了代理（`http_proxy`），测试时加 `--noproxy '*'`，否则可能被本地代理拦成 502。

## 响应格式说明

**思考链**：支持推理的模型会返回 `reasoning_content` 字段（OpenAI 标准里没有，属于 DeepSeek 风格扩展）：

```json
{
  "choices": [{
    "message": {
      "role": "assistant",
      "content": "最终回答",
      "reasoning_content": "推理过程…"
    }
  }]
}
```

**用量**：`usage` 里除标准字段外，还有一个 `credit`（本次消耗的积分），控制面板的记账就是读它。
