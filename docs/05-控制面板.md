# 05 · 控制面板

地址：`http://<你的地址>:8000/admin`（访问 `/` 会自动跳转过来）
密码：`.env` 里的 `ADMIN_PASSWORD`

---

## 概览

| 卡片 | 含义 |
|---|---|
| 剩余积分 | 账号当前可用 credits（来自上游计费接口） |
| 总积分 | 所有资源包的额度总和 |
| 今日消耗 | 今天累计消耗的 credits（来自本服务的请求记账） |
| 今日请求 / tokens | 今天的调用次数与 token 量 |
| 密钥数 | 启用数 / 总数 |
| 累计日志 | 请求日志总条数 |

下面的进度条是「剩余 / 总量」，低于 20% 会变黄。
再往下按资源包拆分展示：每个包的总额度、已用、剩余、使用率。

积分数据有缓存（默认 60 秒，`ADMIN_CREDIT_REFRESH_SEC`），点右上角「刷新积分」可强制拉取。

> 面板顶部还会显示上游地址和套餐名（比如「体验版 · 免费」）。

## API 密钥

### 新建分发密钥

填四个字段：

| 字段 | 说明 |
|---|---|
| 名称 | 给谁用的，比如「小李的 Cherry」 |
| 额度类型 | 不限 / 按次数 / 按积分 / 按 tokens |
| 额度值 | 对应类型的上限，选「不限」时忽略 |
| 有效期（天） | 留空 = 永久 |

创建后**新密钥只完整显示一次**，当场点「复制」。列表里之后只显示 `sk-wb-1234…abcd` 这样的掩码。

### 额度语义

| 类型 | 计量方式 | 适合场景 |
|---|---|---|
| `none` | 不限制 | 自己的客户端 |
| `requests` | 每次调用 +1 | 简单限次，"给他 100 次" |
| `credits` | 累加该次请求上游返回的真实消耗 | 最精确，等于给多少积分额度 |
| `tokens` | 累加 prompt + completion tokens | 按量计费思路 |

额度用尽后请求会直接返回：

```
403 {"detail":"额度已用完（10.02/10 积分）"}
```

是**服务端强校验**，不是前端摆设 —— 客户端改不了。

### 列表里的操作

| 操作 | 说明 |
|---|---|
| 启用 / 禁用 | 禁用后立即生效，返回 `403 该 API Key 已被禁用` |
| 重置用量 | 把已用额度清零（额度值不变），适合按周期给量 |
| 重置 Key | 换一串新的。旧 Key 立即失效，新 Key 只显示一次 |
| 删除 | 彻底删除，不可恢复 |

### 主密钥

`.env` 里的 `API_KEY` 会作为「主密钥」自动出现在列表里，标记为**受保护**：不可删除、不可重置、无额度限制。
这样你已经配好的客户端不用改任何东西。

## 用量统计

时间范围可选 7 / 14 / 30 / 90 天。

- **每日用量**：柱状图（按请求数）+ 表格（请求数、失败数、tokens、消耗积分）
- **按密钥**：谁用得多、谁在报错
- **按模型**：哪个模型最费积分

> 这里的数据是**本服务自己的记账**，只统计经过本服务的请求；
> 上游账号在别处（比如客户端本体）产生的消耗不会出现在这里。

---

## 请求日志

最近 200 条（接口支持最多 1000 条），字段：

| 字段 | 说明 |
|---|---|
| 时间 | 本地时间 |
| 密钥 | 哪个 Key 发起的（主密钥显示「主密钥（.env）」） |
| 接口 | `/v1/chat/completions`、`/v1/models`、`/v1/images/…` |
| 模型 | 请求里的 model 字段 |
| 状态 | 200 绿、4xx/5xx 红 |
| 耗时 | 端到端毫秒数 |
| tokens / 积分 | 上游返回的真实用量 |
| IP | 来源地址 |

「清理 90 天前」用于删掉历史日志，避免数据库无限增长。

## 数据落在哪

| 环境 | 数据库位置 |
|---|---|
| 本机直接跑 | 项目目录下 `admin.db`（可用 `ADMIN_DB` 改） |
| Docker / CasaOS | 容器内 `/data/admin.db`，宿主对应挂载目录 |

想备份/迁移，复制这个文件即可。想彻底重置，删掉它再重启。

---

## 安全建议

面板是明文 HTTP，密码和密钥都会明文过网。所以：

1. **别把 8000 端口直接暴露到公网**，先用反向代理加 HTTPS
2. `ADMIN_PASSWORD` 别用弱口令
3. 分发出去的 Key 一律设额度（`credits` 或 `requests`），出事能立刻禁用
4. 面板不对外开放时，也可以只在局域网访问

## 管理 API（脚本化）

面板本身是纯 API 驱动的，可以拿主密钥当 admin token 直接用：

```bash
KEY=$(grep '^API_KEY=' .env | cut -d= -f2-)
B=http://127.0.0.1:8000

# 概览（积分 + 统计）
curl -s $B/admin/api/overview -H "X-Admin-Token: $KEY"

# 建一个 100 积分、30 天有效的密钥
curl -s -X POST $B/admin/api/keys -H "X-Admin-Token: $KEY" -H 'Content-Type: application/json' \
  -d '{"name":"给小李","quota_type":"credits","quota_limit":100,"expires_in_days":30}'

# 其他
curl -s $B/admin/api/keys                      -H "X-Admin-Token: $KEY"   # 列表
curl -s -X PATCH $B/admin/api/keys/2           -H "X-Admin-Token: $KEY" -H 'Content-Type: application/json' -d '{"enabled":false}'
curl -s -X DELETE $B/admin/api/keys/2          -H "X-Admin-Token: $KEY"
curl -s $B/admin/api/usage?days=7              -H "X-Admin-Token: $KEY"
curl -s "$B/admin/api/logs?limit=100"          -H "X-Admin-Token: $KEY"
curl -s -X POST $B/admin/api/credits/refresh   -H "X-Admin-Token: $KEY"
```

用密码换临时 token 也可以（默认 12 小时有效）：

```bash
TOKEN=$(curl -s -X POST $B/admin/api/login -H 'Content-Type: application/json' \
  -d '{"password":"你的ADMIN_PASSWORD"}' | python -c "import sys,json;print(json.load(sys.stdin)['token'])")
```
